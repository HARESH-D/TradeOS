# Analytics

## Current Build

Analytics starts with dashboard summaries and an Excel-like analysis grid.

Dashboard metrics:
- Net P&L
- Account balance
- Win rate
- Profit factor
- Average win/loss trade
- Trade expectancy
- Drawdown
- Daily and cumulative P&L
- Calendar-style daily P&L

Analysis grid:
- Trade/order level rows
- Column filters
- Sorting
- Global search
- Date range filter
- Symbol filter
- P&L filter
- Segment/product filter
- Export-ready structure for future CSV/XLSX
