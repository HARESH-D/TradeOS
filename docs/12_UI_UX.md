# UI/UX

## Product Feel

TradeOS should feel like a serious trading workspace, not a marketing site.

Visual direction:
- Clean light-mode interface by default
- Left sidebar navigation
- Dense dashboard cards
- Purple/indigo accent color with green/red P&L states
- Large data surfaces with clear filters
- Spreadsheet-style analysis page
- Calendar P&L view inspired by modern trading journal tools
- Responsive, but desktop-first for serious analysis

## Current Build Screens

1. Dashboard
   - Broker connection and sync status
   - Manual sync action
   - Last synced timestamp
   - KPI cards
   - P&L charts
   - Calendar-style daily P&L
   - Recent trades/open positions preview

2. Broker Sync
   - Angel One connection form
   - Sync progress states
   - Success/failure summary
   - Clear reconnect/manual refresh behavior

3. Analysis
   - Excel-like grid
   - Column filters
   - Sorting
   - Search
   - Date range filter
   - Symbol/product filters
   - Detailed trade/order/position rows
